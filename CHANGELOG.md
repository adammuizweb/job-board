# Changelog

## 0.1.2 - 2026-10-27

- Added information-only vacancies that can be published without an application
  URL or email address.
- Omitted application calls to action for information-only vacancies while
  retaining normal public visibility and structured job metadata.

## 0.1.1 - 2026-10-27

- Fixed the dashboard job list failing when loading its workflow status filters.
- Added a packaged SVG icon for installed-plugin and Store surfaces.

## 0.1.0 - 2026-10-27

- Initial release with localized jobs, companies, and categories.
- Added draft, publish, close, archive, and restore workflows with audit logs.
- Added public routes, strict locale visibility, neutral templates, and JSON-LD.
- Added the `job_board_jobs` Preset provider and `job_board_list` widget.
- Added standalone contracts, optional disposable MySQL integration, and safe
  package tooling.
- Added a responsive Core-native dashboard with overflow workflow actions,
  accessible confirmations, dark-mode surfaces, and site-timezone displays.
